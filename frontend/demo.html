Prueba de Integración: Drop-in Chat Widget

Esta página simula un sitio anfitrión (por ejemplo Django templates, Shopify, o portal externo) consumiendo el widget autónomo con Shadow DOM sin colisión de estilos.

Instrucciones de Integración Drop-in

Para incrustar este asistente en cualquier template de Django o sitio web, basta con agregar una única etiqueta de script antes de </body>:

<!-- 1. Drop-in Script Tag -->
<script 
  src="/static/chat-widget.js" 
  data-api-url="http://localhost:8000"
  data-agent="portfolio"
></script>

Características Verificadas

  • Zero-Dependencies: Sin React, jQuery ni librerías externas.
  • Shadow DOM Encapsulation: Cero fuga de estilos CSS.
  • SSE Streaming: Renderizado token a token en tiempo real.
  • Multi-Agent: Selector rápido de agentes especializados.
  • Persistencia: Memoria de sesión vía sessionStorage.
